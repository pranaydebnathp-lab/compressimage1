About Compressify

Compressify is a browser-based file processing website designed to help users work with image and PDF files. Our interface is simple and suitable for everyday use.

Images can be resized and encoded using browser technology. PDF processing is available through the PDF-Lib JavaScript library.

Privacy Policy

Compressify's image processing takes place locally in your browser using JavaScript. This frontend website does not upload your files to a server.

External libraries may be loaded from a CDN. Your browser may make network requests to retrieve those libraries. No personal data collection or storage system is implemented by this frontend.
